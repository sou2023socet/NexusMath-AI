# UI and UX Skill

The platform must support three user modes:

1. Learn:
   Theory, definitions, formulas, examples and prerequisites.

2. Calculate:
   Structured forms, validation, execution and step trace.

3. Explore:
   Graphs, simulations, algorithm animations and experiments.

Every screen should communicate:

- Current domain
- Current topic
- Current operation
- Required inputs
- Validation status
- Execution status
- Result
- Explanation
- Related learning material

Use consistent design for Mathematics, Physics and DSA, but do not force
all domains into identical layouts.

Mathematics needs equation and graph layouts.
Physics needs units, assumptions and simulation controls.
DSA needs execution controls and state visualisation.
