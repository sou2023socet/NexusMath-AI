# DSA Engine Skill

Every algorithm must return:

- Input representation
- Output
- Algorithm name
- Execution steps
- Data structure state
- Operation count
- Time complexity
- Space complexity
- Edge-case behaviour
- Visualisation events

Every mutable operation must produce an event where appropriate:

- COMPARE
- SWAP
- INSERT
- DELETE
- VISIT
- ROTATE
- RELAX
- ENQUEUE
- DEQUEUE
- PUSH
- POP
- MARK_VISITED

Do not mix visualisation logic with the algorithm implementation.
The algorithm generates events; the frontend renders those events.
