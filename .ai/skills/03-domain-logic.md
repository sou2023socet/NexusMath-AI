# Logical Implementation Skill

For every new topic or feature:

1. Identify the domain:
   - MATHEMATICS
   - PHYSICS
   - DSA
   - PLATFORM

2. Identify the category and subtopic.

3. Identify prerequisites.

4. Define:
   - Inputs
   - Outputs
   - Units
   - Assumptions
   - Constraints
   - Invalid cases
   - Precision policy
   - Complexity
   - Visualisation requirements

5. Define the algorithm or formula.

6. Define the step trace.

7. Define the request DTO.

8. Define the response DTO.

9. Implement the domain service.

10. Add unit tests.

11. Add the controller only after the service works.

12. Connect the frontend through an API service.

13. Create the form and validation.

14. Add visualisation if appropriate.

15. Update theory documentation.

16. Update the implementation registry.

Never implement only the final numeric answer. The result must preserve
the reasoning, assumptions and validation information.
