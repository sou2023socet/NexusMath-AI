# Security Skill

- Use stateless JWT authentication.
- Hash passwords with a strong password hashing algorithm.
- Apply role and permission checks at the backend.
- Validate request size and field length.
- Sanitize rendered Markdown and LaTeX.
- Do not expose stack traces.
- Do not log passwords or tokens.
- Do not place secrets in Git.
- Use environment variables or a secret manager.
- Apply rate limits to expensive calculations.
- Restrict administrative operations.
- Verify ownership before returning history records.
