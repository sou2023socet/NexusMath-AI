# Project Structure Skill

You are working on NexusMath-AI, a modular platform for Mathematics,
Physics and Data Structures and Algorithms.

Rules:

1. Keep frontend and backend completely separate.
2. Do not place Java logic inside the Angular project.
3. Do not place UI formatting logic inside Java domain services.
4. Keep controllers thin.
5. Put business logic in services.
6. Put algorithms in domain-engine packages.
7. Put request and response objects in DTO packages.
8. Put reusable validation in validators.
9. Do not create duplicate implementations of the same algorithm.
10. Before creating a file, inspect the existing package structure.
11. Do not rename or delete existing files without approval.
12. Follow the current architecture document before proposing changes.
