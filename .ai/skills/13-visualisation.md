# Visualisation Skill

Backend services must return data, not rendering instructions.

Use domain-specific visualisation events:

Mathematics:
- POINT
- LINE
- CURVE
- VECTOR
- REGION
- FUNCTION_SAMPLE

Physics:
- POSITION
- VELOCITY
- ACCELERATION
- TRAJECTORY_POINT
- FIELD_VECTOR
- CIRCUIT_STATE

DSA:
- ARRAY_STATE
- TREE_STATE
- GRAPH_STATE
- COMPARE
- SWAP
- VISIT
- RELAX
- ROTATE

The frontend must support play, pause, step, reset, speed control and
export where appropriate.
